# DB scuola

Esercitazione di informatica: progettazione di un database scolastico (studenti, classi, materie, voti), dallo schema E-R fino a MySQL/MariaDB.

Il sito è organizzato come un vault di Obsidian, con note collegate, backlink e vista a grafo.

## File

- `index.html` – il sito con tutto lo svolgimento
- `style.css`, `app.js` – grafica e navigazione
- `scuola.sql` – script completo da importare in MySQL/MariaDB (crea tabelle e dati di prova)
